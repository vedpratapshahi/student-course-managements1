## 🌿 Branch Structure

This repository follows a clear branching strategy:

- **master**  
  Stable and final version of the source code.

- **development**  
  Used for active development and testing.

- **build-artifacts**  
  Contains compiled build files such as:
  - `.jar`
  - `.war`

---

## 📦 Build Artifacts

The JAR and WAR files are available in the **build-artifacts** branch.

Example:
target/
├── student-course-management-0.0.1-SNAPSHOT.jar
└── student-course-management-0.0.1-SNAPSHOT.war
> Note: These files are included for deployment and demonstration purposes.
